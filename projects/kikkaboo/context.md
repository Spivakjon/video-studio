# Kikkaboo — business-project context

Active Kikkaboo products, reference materials, and anything Claude should know when producing videos for this brand.

## Products (known)

- **I-VAN** — car seat (Group 0+/1/2/3, ISOFIX + Top Tether). Light-grey / cream colorway. Reference video at `videos/ivan-demo/`.

## Visual identity

- Primary canvas: deep navy `#0B1F3A`
- Accent: safety-orange `#FF6B35`
- Success / verified: green `#00D68F`
- Fonts: Rubik (display) + Heebo (body)
- Logo: black KB monogram — invert on dark backgrounds.

## Tone

- Hebrew first, professional, parent-facing, reassuring.
- B2C and some B2B (retail partners).
- Safety comes before cute — no cartoonish graphics for safety products.

## Linked source folder

When `sourceDir` is set in `project.json`, Claude may scan it for product spec sheets, press photos, existing marketing copy, and feedback. If empty, Claude works from this file only.
