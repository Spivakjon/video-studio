# Social Short — 9:16 vertical

תבנית אנכית לסושיאל מדיה:
- **1080×1920**
- **~18 שניות**
- 4 סצנות: Hook → Tip 1 → Tip 2 → CTA

## אחרי scaffolding

1. שים תמונת מוצר ב-`assets/hero.gif` (או החלף את הסוג של ה-img ב-HTML)
2. פתח את העורך ועדכן טקסטים
3. רנדר

## זמני סצנות

| סצנה | Start | Duration | תפקיד |
|------|-------|----------|-------|
| S1 Hook | 0 | 3s | תופס את העיכוב — שאלה/הבטחה |
| S2 Tip 1 | 3 | 5s | טיפ / תכונה ראשונה |
| S3 Tip 2 | 8 | 5s | טיפ / תכונה שנייה |
| S4 CTA | 13 | 5s | קריאה לפעולה + מותג |

## הערות עיצוב

- Typography בולטת (180-220px) — מתאימה לקריאה במכשיר נייד
- תנועות חדות (0.3-0.4s) — אין זמן ל-dwelling
- רקע כהה שולט; המוצר הוא ההתמקדות
